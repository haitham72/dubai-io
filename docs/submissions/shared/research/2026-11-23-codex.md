## R2 · Local background removal for user stickers

“U-Net” names an architecture. The original Freiburg release is the biomedical implementation with an “archive” of “185MB” that includes code and dependencies. The release page gives no sticker checkpoint, browser runtime or weight licence for commercial sticker use. The relevant U-Net-family entry below is Qin et al.’s **U²-Net**, with general salient-object checkpoints. Compare named exports because licence, download size and runtime depend on the exact artifact. **Recommendation.** Use a pinned U²-Net-P ONNX checkpoint for the MVP, with the Apache licence and attribution retained, and distinguish the checkpoint licence from the unresolved training-data question before commercial release. The author’s portable checkpoint and deployed browser example give it the strongest size and general-subject fit here. Run ONNX Runtime Web on-device. Start with WASM for broad coverage and enable WebGPU after testing the exact artifact on the target browsers. ONNX Runtime's guidance for “very lightweight models” is to “keep using the default WebAssembly (WASM) execution provider.” Browser API availability and support for the model's particular graph and precision are separate checks. [U²-Net paper](https://arxiv.org/abs/2005.09007) · [Maintainer licence statement](https://github.com/xuebinqin/U-2-Net/issues/208) · [ONNX Runtime WebGPU guidance](https://onnxruntime.ai/docs/tutorials/web/ep-webgpu.html) · [Browser support matrix](https://onnxruntime.ai/docs/get-started/with-javascript/web.html)

**Fallback.** If WebGPU is unavailable or fails, retry the same model in WASM. If an automatic mask still fails, use manual mask correction or let the user cancel. For an explicitly selected portrait, the project's planned MediaPipe Selfie option can “segment the portrait of a person”. It cannot serve as the general fallback for pets, objects and food. Candidate validation should include those three classes plus people, fine edges, multiple objects and clutter. Measure cold download, session startup and warm inference separately and check the alpha edge on actual stickers before deciding whether larger weights improve the user flow. [Google MediaPipe model scope](https://developers.google.com/edge/mediapipe/solutions/vision/image_segmenter) · [Project decision D8](../founder-decisions.md#d8--messenger-m0-confirmed-import-and-rebrand-may-start-23-nov)
