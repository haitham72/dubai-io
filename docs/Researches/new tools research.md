## Three jobs

### Hindsight

Retains structured facts, experiences, entities and time links; consolidates observations. Recall fuses semantic, keyword, graph and temporal search. Best fit for "what happened, when, and how are people linked?"

### Honcho

Stores messages, then derives conclusions about each participant. Its context/chat/APPs return a person-centered representation or reasoned answer. Better for "what should the agent understand about this person?"

### edgextract

Not a memory store. It proposes typed edges and asks a constrained yes/no question per candidate, then gets by score/outcome. Use as a cautious extraction stage before graph writes, not as a replacement.

My pick: drop Honcho for the first demo. Hindsight covers the factual/temporal graph; edgextract gives a visible confidence/review gate. Add Honcho back only if tests show person-level conclusions are missing.
