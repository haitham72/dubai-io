# Privacy & Memory FAQ

**What does Lower do?** Lower reduces that memory's weight without deleting its text or sources. It stops influencing Chat, Today and recommendations. You can still find it under Lowered in Memory Vault. Restore removes the override.

**What happens when I select Delete my data?** The request revokes your sessions and memory tokens, removes your data from external queries immediately, and clears its Redis and application caches. We keep an isolated de-identified backup for training. It excludes Google Workspace and YouTube data and has no app or API access.
