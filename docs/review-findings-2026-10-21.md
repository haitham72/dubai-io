## Verified strengths

- The fixed-price action path keeps approval snapshots, host-owned catalog prices, idempotency and provider evidence separate from LLM text. Missing adapters preserve blocked drafts rather than inventing success.
- Mini-apps retain a separate origin, an opaque sandbox and a constrained host bridge. The browser order check reached approval and SUBMITTED in review data.
- Cross-owner legacy memory access and anonymous Luna calls were corrected earlier in this session, with regression coverage.
- Browse categories collapse into chat with one composer; Back/Escape preserve browsing and drafts. Wi-Fi and animated gradient onboarding remain intact.
- Maps now defaults to explicit live Google 2D; 3D demo is selected separately. Late responses/errors cannot silently swap engines. Category options replace the parent row, Back restores categories, and selection uses cyan. Current screenshot: `output/playwright/maps-single-row-cyan.png`.
