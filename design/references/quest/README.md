# Quest App UI Reference Screens (`design/references/quest/`)

**Status:** Permanent Founder Visual Ground Truth · **Lock: NEVER REMOVE OR MODIFY**

This directory contains the original reference screenshots of the Quest personal AI agent application. They serve as the definitive visual and architectural design reference for the **Know** (Memory tree & User profile), **Notice** (Proactive cards), and **Do** (Connectors) UI surfaces.
