## Changes

| Files | Behavior |
|---|---|
| `live/triples.py` | Code-only EN/AR/Arabizi parsing of narrow owner assertions, original character spans, dated facts, and optional place entities. Plans and wants are inferred hypotheses. Restricted turns retain quarantine category and record ID without retaining the source text on this path. |
| `live/topics.py` | Whole-phrase subject matching, unambiguous alias affiliations, and an owner-scoped distinct-session counter. An eligible subject yields one inferred hypothesis citing two surviving sessions at creation. Held-back roots, family, and tagged sensitive subjects are excluded. |
| `queue/session.py`, `queue/worker.py`, `config.py` | Durable session metadata on existing records, transactional session close and outbox enqueue, configured local Qwen first, and existing P1 fallback timing for Haiku. Session/Celery day attempts filter duplicate assertions using evidence and typed triples, with a conservative fallback for legacy text-only outputs. |
| `api/bridge.py` | Hooks owner-device `/records` calls in `extract.live` mode for the `live` and `chat` source families. Requires the record author to equal the authenticated owner to derive facts or topics. Existing Messenger/Community/import modes retain their enqueue behavior. |
| `tests/test_triples.py`, `tests/test_topics.py`, `tests/test_session_job.py` | Trap scoring, attribution, topics, quarantine storage, close/retry, erased inputs, routing/fallback, dedupe and latency against synthetic data. |

An explicit session comes from `records[].meta.session_id`, with a top-level `session_id` default. Clients can close it with `POST /records` using `{"session_id":"…","close_session":true}`. Empty close also works for the most recent implicit session. Implicit sessions use server receipt time and `TM_SESSION_IDLE_MINUTES` (default 30). The existing reconcile beat flushes idle sessions. An explicit ID is closed once, so a new turn after close needs a new ID. Exact retries remain safe.

## Contract requests and limits

1. Reconcile S7's booking and wish labels with the frozen U0c contract. Current literal precision does not clear the fixture threshold until the predicate mismatch is resolved.
2. For the privacy release gate, extend the source-Forget path to revoke an already-published U2 topic hypothesis when one of its two cited visits is erased. U2 ignores erased records in future counts and excludes them from subsequently closed session jobs. The existing shared-evidence Forget behavior can trim a published hypothesis to one source; U2's owned files do not change that behavior.
3. Celery session/day catch-up applies the duplicate guard. Direct MCP/manual submissions bypass the worker hook. If those paths process live records, move the typed tuple check into their shared submit/apply contract. Legacy text-only paraphrase dedupe is conservative and may abstain from filtering unfamiliar forms.
4. The latency check uses an isolated Postgres database schema and app TestClient. Remote client latency, full-size topics under concurrent ingest, actual LM Studio/Haiku connectivity, and production workload performance remain unmeasured.
