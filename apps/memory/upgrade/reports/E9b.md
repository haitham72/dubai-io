## Priority 2 (coordinator): live context pack and semantic recall
Findings: `live/context.py` already calls the same `search_candidates` as `/search` (RRF incl. semantic). It got no semantic hits because (1) NOTHING wrote embeddings for live-extracted facts: only the S10 harness / an `embed.backfill` job nobody enqueued; no embeddings -> `has_emb` false -> channel silently skipped; (2) the memory Docker image installed `[cloud,mcp]` without `[semantic]` (no onnxruntime); (3) failures were swallowed with no signal; (4) bge-m3 cosine for "sport" vs "surf school" is only 0.34 (same as unrelated pairs, e.g. 0.43 for "weather forecast" vs a VAT fact), so no threshold can make that paraphrase work semantically.
Fixes: `embed.ensure_embeddings` (never raises): embeds new facts right after every apply (applier) and lazily once per owner per facts_version on the first semantic query; Dockerfile now `.[cloud,mcp,semantic]`; `retrieval.LAST_SEMANTIC` status; context pack returns `retrieval: {semantic: ok|no_embeddings|embedder_unavailable|disabled, channels:[...]}` and does not cache a degraded pack; `/health` has `semantic:{enabled,deps_installed,loaded,model}`; deterministic synonym group sport/surf/football/padel/running/... so "sport" finds the surf school fact (lexical expansion); no recent-facts padding on this path (unrelated query returns []).
Embedder: BAAI/bge-m3 int8 ONNX (Xenova/bge-m3) via onnxruntime on CPU, in-process in the memory API / worker process, 1024-d pgvector. NO LM Studio needed. It downloads ~570 MB from Hugging Face on first use (cached afterwards); the founder PC (host venv) already has it cached. The memory Docker image must be REBUILT (new extra) and needs internet for the first model download or a mounted HF cache; until then chat degrades honestly to lexical + synonym + entity/subject with `semantic: embedder_unavailable`.
Tests (tests/test_live_semantic.py): "sport" -> surf school and a zero-overlap paraphrase -> passport with semantic on, lazily embedded; unrelated query -> []; embedder unavailable -> lexical works, paraphrase gets [] and the flag; TM_SEMANTIC=0 flag.
