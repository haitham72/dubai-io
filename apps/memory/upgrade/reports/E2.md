## Founder manual run sheet
1. `scripts/dev/start-all.ps1`; open Expo web (`http://localhost:8081`) -> Connect -> **Sign in with Google** -> pick your account. You return to Connect showing your name/email.
2. Connect -> **Pair your iPhone**: QR appears (valid 5 min, one use). In Connect on the iPhone set API Server URL to `http://<PC LAN IP>:8000` (same Wi-Fi), tap **Scan QR to Pair iPhone**, scan.
3. Both show your name (Connect account card; Today greeting). Signed-in devices lists PC + iPhone.
4. Desktop app: sign in (same flow; loopback), then Sync now - needs the source consent turned on in Connect first.
5. On the PC Connect -> Signed-in devices -> **Revoke** the iPhone. Phone's next request gets 401 and it falls back to signed-out.
Expired/reused QR shows "Pairing code expired / already used - generate a new QR".
